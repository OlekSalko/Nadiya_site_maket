# Nadiya_site_maket

Статичний mobile-first макет сайту забудовника «Надія Девелопмент» (HTML5, CSS3, vanilla JS).

## Запуск

Відкрийте `index.html` у браузері або запустіть локальний сервер:

```bash
python3 -m http.server 8000
# http://localhost:8000
```

## Сторінки

| Сторінка | Файл |
|---|---|
| Головна (hero з відео, проєкти, переваги, хід будівництва, CTA) | `index.html` |
| Усі об'єкти (у продажу / архів / комерційна) | `html/properties.html` |
| Сторінка ЖК — шаблон (галерея, шахматка, хід будівництва, локація) | `html/property.html` |
| Вибір квартири (фільтри, сортування) | `html/apartments.html` |
| Контакти | `html/contacts.html` |

Форма заявки доступна з будь-якої сторінки через плаваючу кнопку «Зв'язатися» та кнопку в шапці.

## Структура

- `css/` — `base.css` (токени, reset, типографіка), `components.css` (шапка, футер, кнопки, картки, модалки, форми), `pages.css`
- `js/` — `main.js` (меню, модалки, форми), `data.js` (дані ЖК і квартир), `chessboard.js`, `filters.js`, `apartment-modal.js`, `tabs.js`, `gallery.js`, `subnav.js`, `home.js`
- `assets/` — лого, презентаційне відео, кадри з відео, SVG-планування, іконки

Усі дані (ЖК, квартири, ціни, контакти) — вигадані плейсхолдери.
